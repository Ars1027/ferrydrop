# 演示录屏脚本

录屏使用真实设备与实际运行数据。先准备 Windows 电脑、两台安卓手机或两部独立客户端、同一可信网络、至少三个不同账户、两种身份策略。证书信任预先配置，录屏中展示验证结果，不展示密码和私钥。

1. **构建与启动。** 从源码执行 npm ci、npm run build；展示构建成功与本地 HTTPS 页面，说明服务端运行位置。
2. **安全连接与身份。** 展示证书受信和访问地址匹配；首次登记设备后刷新，通过设备签名自动连接。展示撤销设备后被拒绝。
3. **房间配对。** Windows 创建房间，安卓扫码申请，房主审批。解释房间码不能替代账户认证。
4. **确认交付。** 选接收设备和多个文件，展示接收方确认之前文件未上传；接受后查看真实进度。手机点击保存，并打开一份文本或图片验证内容。
5. **双向和多用户。** 同时从安卓发回文件，另一台安卓加入同一服务端，演示手机之间互传和多任务队列。
6. **断点恢复。** 用足够大的文件，在传输中断网；重连后续传。刷新发送页时重新选择同一文件；展示不同文件被拒绝恢复。再展示服务端重启后确认偏移仍在。
7. **身份带宽。** 用明显高于限速的局域网和足够大的文件，比较普通与 VIP 的持续传输；同用户多个连接的总额度不叠加。记录测量窗口，不能用瞬时数字代替持续速率。
8. **安全拒绝。** 运行 SQL 注入、Origin、跨账户任务访问和协议长度测试；展示实际拒绝结果。说明应用限流与网络带宽防护的区别。
9. **临时副本生命周期。** 展示确认完成后服务端临时文件被删除，而接收方仍能保存本地文件；取消或过期任务不能继续恢复。
10. **收尾。** 展示报告中的协议头图、各模块时序图、运行目录 ACL 和真实 Git 地址。

画面中出现错误时保留正确解释与修复过程，最终演示结果需成功。录屏完成后提供真实 MP4，提交脚本负责命名和打包；不以自动化截图冒充真机录屏。
