## 自动化契约

1. **协议帧。** 正常编解码、截断报头、不支持版本、非法保留位、超长载荷及不安全偏移。
2. **三用户。** 房间审批、接收同意、任务隔离、双向多文件、零字节与取消。知道其他用户的任务 ID 仍不能操作。
3. **设备身份。** P-256 密钥互操作、错误密钥与已消费挑战拒绝、撤销后认证拒绝、非管理员不能修改身份策略。
4. **恢复。** 正常服务重启后继续已确认上传；下载连接中断后按偏移重取并恢复原字节。另启动独立子进程，在收到上传 ACK 后强制终止进程，重启后继续并通过完整 SHA-256。
5. **错误哈希。** 文件不能进入可下载状态，暂存内容清理。
6. **身份聚合。** 同账户两个连接的三个上传信用共享预算；限速等待时心跳仍能响应。
7. **攻击与生命周期。** SQL 注入式用户名/口令不能登记；错误 Origin 被拒绝；路径穿越式文件名仍以服务端 UUID 存储；超大文件、超大帧拒绝；房间自然到期拒绝新申请/新任务，旧授权任务可恢复；任务保留期结束后拒绝恢复并实际删除文件。
8. **TLS。** 显式信任正确 CA 的客户端可以连接；未信任 CA、服务身份名称不匹配均失败。测试没有关闭证书验证。
9. **账户。** 创建账户与设备登记使用一致的 10—256 字符口令范围，边界可登录，超长/过短在创建时拒绝。
10. **房间关闭。** 关闭后删除数据库房间记录并取消未完成任务、清理暂存文件；双方界面移除房间号与二维码，刷新后不再出现。旧版本残留的关闭房间在启动时清理，完成的传输回执和浏览器已接收文件保留。

刷新回归：完成交付并关闭房间后，同时刷新发送和接收页面；已结束任务不发送 RESUME_QUERY，不弹出 Request rejected，接收方仍能从浏览器本地副本保存文件。只对有源文件的未完成上传，以及待接收/接收中的下载执行恢复。

## 浏览器实际流程

2026-11-11 保存兼容性回归：安卓窄屏与 Windows 桌面上下文均使用单一“保存到设备”按钮。无论系统文件选择器不存在还是会抛 AbortError，均通过浏览器下载；已核对导出文件名及内容。窄屏上下文不代替 Android 真机测试。

两个隔离上下文分别登记账户和设备，经房主审批连接。发送两个文件，接收方确认之前没有开始上传；确认后下载到 OPFS，读取真实文件文本与预期比较。再反向发送一个文件，确认双方完成回执与服务端清理。刷新后通过保存的设备私钥重新认证，已接收文件仍可导出。测试实际触发 Blob 下载并核对文件名，检查窄屏无水平溢出和页面无未处理异常。

截图在 `assets/readme/`，由上述测试生成，覆盖登记、接收确认、真实传输中和完成后桌面/窄屏状态。截图内设备名称是测试输入，设备操作系统并非自动识别结果。

## 使用边界

服务端可信并可读取暂存文件。应用限流不承诺抵御超出网络入口带宽的洪泛。恢复已验证到正常重启及强制进程终止，不承诺硬件掉电或磁盘损坏后恢复。同步分块落盘与 SQLite FULL 提交优先保证确认顺序，高负载性能需要单独测量。浏览器站点数据清除或存储回收会使本地接收内容及设备密钥丢失。
